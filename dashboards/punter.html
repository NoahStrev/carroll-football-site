Punter

Individual punter breakdown from the real Carroll Punt sheet in Carroll_Special_Teams_2021_Current.xlsx (247 punts, 2021–2025) — position 3 of the special-teams series, alongside Placekicker and Kickoff Kicker. Gross distance, net distance (gross − return yardage), Inside-20 rate, touchback rate, outcome mix, and quarter/season splits are all box-score-derived and fully real for every row. Hangtime, Snap to Catch, Catch to Kick, and Hash Kicked From are hand-charted from film and only exist from 2023 onward (0% charted 2021–2022, effectively complete by 2024–2025) — charts using them only ever average the rows actually charted. Punt Value/Score is a real, fully-computed "points added over expectation" metric already in the source workbook. Known data issue, not fixed here — the source has a bare-surname capture, "Streveler" (4 rows, 2021 only), alongside the full name "Noah Streveler" (145 rows, 2022–2024) for what's almost certainly the same punter (a documented name-parsing gap in the Special Teams Data project, not something to merge here — see the Placekicker/Kickoff Kicker pages for the same category of issue). Snapper Name is blank for every punt in this sheet — tracked instead on the upcoming Long Snapper page.
