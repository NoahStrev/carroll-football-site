Rankings

Carroll's own conference and national statistical rankings, read directly from the CCIW Buddah Report and National Buddah Report projects' own already-scraped, already-classified output — this page doesn't re-scrape either source itself. CCIW Rankings (cciw.org, out of the conference's 9–10 teams, 2016–2025 except 2020) apply whenever an opponent is a CCIW conference team; National Rankings (NCAA.com D3, out of ~200+ programs nationally, 2021/2023–2025) apply to any opponent, conference or not. Overall has no CCIW-scope data — a real, permanent gap, not a bug: cciw.org's own site never publishes Turnover Margin, Winning %, or Penalties as their own ranked category the way NCAA.com does, so that tab only ever has a National-scope table. Special Teams rounds out the four phases the source data actually splits into (matching what each report's own PDF already shows) — it complements rather than duplicates the Special Teams Overview dashboard, which goes far deeper per-unit but has no CCIW/national ranking context of its own. Team-level only for this first pass (no individual-leader rankings yet). Both source workbooks are downloadable in full below each table. Not yet automated: both pipelines' own weekly data scrapes already run on a schedule, but re-generating this page's data from their output is still a manual step (python scripts/build_rankings_data.py) — wiring that up end-to-end is a deferred follow-up, not built here.
