Lifting & Strength

Rebuilt from the Lifting Data pipeline (five seasons, 2021-22 through 2025-26, each max-out session's best Bench/Squat/Clean and their Combined Total). Class year (Freshman/Sophomore/ Junior/Senior) is derived from years-with-program, which the Lifting Data project confirmed matches the source's own class field exactly wherever both exist — but that's only 2023-24 onward, so 2021-22/2022-23 sessions only appear in the All Time / Last Session tab, never a class-specific one. "Att Date" from the original Tableau version is shown here as testing session (football year + December/January/April) — the source data tracks by session, not an exact calendar date.
