Lifting & Strength

Rebuilt from the Lifting Data pipeline (five seasons, 2021-22 through 2025-26). Class year (Freshman/Sophomore/Junior/Senior) is derived from years-with-program, which the Lifting Data project confirmed matches the source's own class field exactly wherever both exist — but that's only 2023-24 onward, so 2021-22/2022-23 sessions only appear in the All Time / Last Session tab, never a class-specific one. "Att Date" from the original Tableau version is shown here as testing session (football year + December/January/April) — the source data tracks by session, not an exact calendar date. Every leaderboard group is now split into two sections: Strength (Combined Total, Bench, Squat, Clean, and Strength Score — a team-wide percentile averaged across those three lifts' z-scores) and Athletic Testing (Broad Jump, Vertical, Pro Agility, and Athleticism Score — a percentile across all six of Bench/Squat/Clean/Broad Jump/Pro Agility/Vertical). Pro Agility is a timed sprint, the one metric here where a lower number ranks first. Athleticism Score only exists for 2023-24 and 2025-26 — it requires all six contributing metrics in the same session, and Vertical/Pro Agility don't both exist in every year (Pro Agility itself has no data at all in 2024-25 — a real gap in that year's testing, not a bug here). Both scores are team-scope only — each athlete's percentile against the whole roster that session, not just their position group; a position-scope version exists in the source data and could be added later. See the Lifting Data project's own SKILL.md for the full z-score methodology.
